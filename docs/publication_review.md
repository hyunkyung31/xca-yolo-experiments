# 데이터 공개 범위 및 원본 보존

## 1. 공개 범위

이 저장소는 관상동맥조영술(XCA) 영상의 협착 탐지 실험을 정리한 개인 포트폴리오입니다.

실험에 사용한 원본 의료영상과 데이터셋은 공개하지 않고, 코드와 실험 결과를 확인할 수 있는 집계 자료만 포함했습니다.


### 공개 자료

| 구분 | 공개 내용 |
|---|---|
| 실험 코드 | 데이터 분석, 이미지 전처리, 모델 학습 및 평가 코드 |
| 실험 노트북 | 주요 코드와 결과를 유지한 공개용 노트북 11개 |
| 성능 지표 | YOLO 및 Faster R-CNN 평가 결과, 전처리 품질 지표 |
| 시각화 자료 | Bounding Box 분포, 전처리 품질, 모델 성능 비교 그래프 |
| 실험 문서 | 실험일지, 실행 환경, 결과 출처 및 한계 |

### 공개하지 않은 자료

| 구분 | 처리 내용 |
|---|---|
| 원본 의료영상 | GitHub 업로드 대상에서 제외 |
| 병변 및 전처리 이미지 | 원본 영상이 포함된 시각화 17개 비공개 처리 |
| 개별 Annotation | 이미지 ID, 좌표 등 개별 데이터 출력 제외 |
| 학습 가중치 | 모델 체크포인트 및 대용량 학습 산출물 제외 |
| 개인 환경 정보 | 개인 서버의 절대경로를 상대경로로 수정하거나 익명화 |
| 원본 ZIP | 공개 저장소 외부에 별도 보존 |

원본 의료영상뿐 아니라 원본 영상을 가공한 Crop 이미지와 전처리 결과도 데이터 공개 조건이 확인되기 전까지는 공개하지 않습니다.

## 2. 원본 파일 및 실험 결과 보존

기존 실험 결과를 정리하면서 원본 코드와 중요한 평가 지표가 사라지지 않도록 구분해 보존했습니다.

원본 ZIP은 수정하지 않았으며, 파일별 해시값과 변경 내역은 `docs/source_manifest.json` 및 `docs/change_report.md`에 기록했습니다.

노트북에서 추출한 주요 자료는 다음과 같습니다.

- 원본 출력에 포함된 PNG 22개 중 의료영상 관련 17개는 공개 제외
- 의료영상이 포함되지 않은 기존 집계 그래프 5개 보존
- 성능 비교표와 Epoch별 학습 이력을 CSV로 정리
- 주요 학습 결과와 오류 기록을 별도 텍스트로 보존
- 공개용 노트북에서는 반복 진행 로그와 불필요한 출력 정리

이후 기존 CSV를 활용해 전처리 품질, YOLO11n 성능, Faster R-CNN 학습 이력을 다시 시각화한 그래프 3개를 추가했습니다.

새로운 그래프는 기존 평가 수치를 바탕으로 작성했으며, 시각화 과정에서 모델을 다시 학습하거나 추론하지 않았습니다.

현재 공개 저장소에는 기존 집계 그래프 5개와 재시각화 그래프 3개가 포함되어 있습니다.

원본 ZIP과 공개 제외 자료는 GitHub 저장소 밖에 보존했으며, 별도의 영구 백업 여부는 추가 확인이 필요합니다.

## 3. 개인정보 및 보안 관련 검토

공개 저장소를 정리하면서 의료영상, 개별 Annotation, 개인 환경 경로 및 인증정보가 포함되어 있는지 확인했습니다.

의료영상과 개별 데이터 출력은 공개 자료에서 제외했으며, 코드에 포함된 개인 서버 경로는 가능한 범위에서 프로젝트 기준 경로로 변경했습니다.

또한 GitHub 토큰, API Key, 비밀키, 이메일 주소 등 민감정보가 포함되어 있는지 알려진 패턴을 기준으로 점검했습니다.

점검 과정에서 해당 패턴과 일치하는 항목은 발견되지 않았지만, 자동 검사만으로 모든 개인정보나 인증정보의 부재를 보장할 수는 없습니다.

따라서 새로운 데이터나 노트북 출력을 추가하는 경우에도 공개 가능 여부를 별도로 확인해야 합니다.

## 4. 추가 확인이 필요한 사항

현재 저장소에는 코드와 집계된 실험 결과를 공개하고 있지만, 아래 사항은 추가 확인이 필요합니다.

- ARCADE 데이터셋의 정확한 버전과 사용·재배포 조건
- 데이터의 비식별화 및 환자 단위 분할 여부
- 사용한 사전학습 모델과 외부 코드의 라이선스
- 기존 학습 환경의 정확한 패키지 버전 및 CUDA 설정
- 원본 학습 CSV와 모델 체크포인트의 확보 가능 여부
- 별도 Test 데이터 및 외부 검증을 통한 성능 재현 여부

현재 공개된 성능 지표는 기존 노트북에 저장된 실험 결과를 기준으로 합니다.

데이터 사용 권한과 실험 환경이 완전히 확인되지 않았으므로, 이 저장소의 결과를 의료 진단 성능이나 임상적 유효성을 검증한 자료로 해석해서는 안 됩니다.

실험별 결과와 한계는 [실험일지](experiment_summary.md), 재실행에 필요한 환경과 설정은 [재현성 문서](reproducibility.md)에 정리했습니다.
