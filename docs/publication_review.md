# 데이터 출처 및 공개 범위

이 저장소는 ARCADE 데이터셋을 이용해 관상동맥조영술(XCA) 영상의 협착 탐지 모델을 실험한 개인 포트폴리오입니다.

실험 과정에서 작성한 코드와 모델 평가 결과를 중심으로 구성했으며, 원본 의료영상이나 데이터셋 전체를 GitHub에 재배포하지는 않았습니다.

## 1. 데이터셋 출처 및 이용 조건

이 프로젝트에서는 **ARCADE(Automated Region-based Coronary Artery Disease diagnostics using x-ray angiography imagEs)** 데이터셋의 협착 탐지 자료를 사용했습니다.

- **공식 사이트:** [ARCADE Challenge](https://arcade.grand-challenge.org/)
- **데이터 배포:** [Zenodo — ARCADE](https://zenodo.org/records/7981245)
- **등록 안내:** [ARCADE Registration](https://arcade.grand-challenge.org/registration/)

ARCADE 공식 안내에는 CC BY-NC-SA 이용 조건과 데이터 접근을 위한 등록 절차가 명시되어 있습니다.

CC BY-NC-SA는 출처 표시(BY), 비상업적 이용(NC), 동일조건변경허락(SA)을 요구하는 라이선스입니다. 다만 실제 사용한 데이터 버전과 등록 시 적용된 추가 이용 조건은 별도로 확인해야 합니다.

데이터셋의 연구 목적 사용과 원본 영상 또는 Annotation 파일의 재배포는 구분했습니다.

## 2. GitHub 공개 자료

현재 저장소에는 다음 자료를 중심으로 정리했습니다.

| 구분 | 공개 내용 |
|---|---|
| 실험 코드 | 데이터 분석, 영상 전처리, YOLO 및 Faster R-CNN 학습·평가 |
| Jupyter Notebook | 실험 단계별 노트북 11개 |
| Python 스크립트 | 데이터 변환, ROI Crop 및 Cascade 구현 |
| 평가 결과 | Precision, Recall, mAP, AP50 및 전처리 품질 지표 |
| 시각화 | 협착 bbox 분포, 전처리 품질, 모델별 성능 및 학습 이력 |
| 기술 문서 | 프로젝트 소개, 실험일지, 재현성 및 평가 결과 설명 |

실험 결과를 확인할 수 있도록 주요 성능표와 학습 이력을 CSV로 정리했습니다.

일부 그래프는 저장된 실험 결과를 바탕으로 다시 시각화했으며, 새로운 모델 학습이나 추론을 수행해 생성한 수치는 아닙니다.

## 3. 공개하지 않은 자료

| 구분 | 공개 범위 |
|---|---|
| 원본 의료영상 | 저장소에 포함하지 않음 |
| 의료영상 기반 시각화 | 원본 Frame, 병변 ROI 및 전처리 예시 등 제외 |
| 개별 Annotation | 환자·영상별 좌표 및 개별 데이터 출력 제외 |
| 학습 가중치 | YOLO, Faster R-CNN의 Checkpoint 파일 제외 |
| 원본 데이터셋 | ARCADE 원본 데이터와 압축파일 제외 |
| 개인 환경 정보 | 서버 절대경로 등은 상대경로로 변경하거나 익명화 |

원본 영상에서 생성한 Crop과 전처리 이미지도 공개 범위를 별도로 검토해야 하는 자료로 구분했습니다.

현재 저장소에는 원본 이미지 대신 집계 그래프와 성능 비교 자료를 활용하고 있습니다.

## 4. 실험 자료 보존

실험 중 생성된 결과와 공개용 자료는 구분해 관리했습니다.

원본 노트북의 저장 출력에는 PNG 이미지 22개가 포함되어 있었으며, 이 중 의료영상과 관련된 17개는 공개 자료에서 제외했습니다.

나머지 집계 그래프 5개는 실험 결과 확인에 활용할 수 있도록 유지했습니다.

추가로 기존 CSV 데이터를 이용해 다음 세 가지 그래프를 작성했습니다.

- 전처리별 ROI 품질 비교
- YOLO11n의 최종 검증 성능 비교
- Faster R-CNN의 Epoch별 AP50 변화

따라서 저장소에는 기존 집계 그래프 5개와 추가 시각화 그래프 3개를 포함했습니다.

성능 비교표와 학습 이력은 CSV로 정리했고, 실험 결과에 영향을 주는 학습 설정과 평가 기준은 유지했습니다.

공개용 자료를 정리하는 과정에서 원본 노트북의 코드와 평가 결과가 임의로 변경되지 않도록 구분했습니다.

원본 ZIP과 공개하지 않은 의료영상은 GitHub 외부에 보관했습니다. 다만 별도의 영구 백업 및 복원 가능 여부까지 검증한 것은 아닙니다.

## 5. 개인정보 및 보안

의료 데이터가 포함된 프로젝트이므로 영상과 Annotation뿐 아니라 코드에 포함된 경로와 인증정보도 검토했습니다.

공개용 노트북에서는 의료영상 출력과 개별 데이터 예시를 제외하고, 개인 서버의 절대경로는 가능한 범위에서 프로젝트 상대경로로 수정했습니다.

GitHub 토큰, API Key, 비밀키 등은 알려진 문자열 패턴을 기준으로 점검했으며, 검사 범위에서 해당 패턴과 일치하는 인증정보는 발견되지 않았습니다.

다만 이러한 점검만으로 모든 개인정보나 인증정보가 존재하지 않는다고 보장할 수는 없습니다.

새로운 데이터, 노트북 출력 또는 시각화 자료를 추가할 때에도 데이터셋 이용 조건과 공개 범위를 확인할 필요가 있습니다.

## 6. 추가 확인 및 개선할 사항

현재 저장소는 기존 실험의 코드와 성능 결과를 살펴볼 수 있도록 구성했지만, 다음 사항은 추가 확인이 필요합니다.

- ARCADE의 실제 사용 버전과 정확한 CC BY-NC-SA 라이선스 버전
- 데이터 등록 및 접근 승인 과정에 적용된 추가 이용 조건
- 데이터 분할 과정에서 환자 단위 중복이나 데이터 누수가 있었는지 여부
- 외부 사전학습 모델 및 라이브러리의 라이선스
- 기존 학습 환경과 패키지 버전
- 원본 학습 CSV 및 모델 Checkpoint 확보 여부
- 별도 Test 데이터와 외부 검증을 통한 성능 평가

실험에서 얻은 성능은 사용한 데이터와 평가 조건에 따른 결과이며, 실제 임상 환경에서 진단 성능이나 유효성을 검증한 것은 아닙니다.
